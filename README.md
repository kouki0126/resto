# Restaurant Management Application

Application web Full-Stack développée avec React.js et Django REST Framework dans le cadre d'un projet universitaire.

## Technologies

- React.js
- Django REST Framework
- PostgreSQL
- JWT
- HTML
- CSS
- JavaScript

## Fonctionnalités

- Authentification avec JWT
- Gestion des plats
- API REST
- Interface utilisateur responsive

## Contexte

Projet académique réalisé en binôme à la Faculté des Sciences de Meknès.
